# CreditLens - Loan Risk Lakehouse (PySpark + Delta Lake on Databricks)

An end-to-end data engineering project that turns messy retail-loan files into a clean, tested,
analytics-ready **medallion lakehouse** and a risk mart that answers: *which loan grades and vintages are losing money?*
Phase 2 adds an **AI agent** that answers questions over the gold tables.

> All data is **synthetic** and generated by `src/creditlens/datagen.py`. No real customer or employer data is used.

## Architecture

```
 raw CSV files (Unity Catalog Volume)
        |  customers.csv  loans.csv  payments.csv   (dirty on purpose)
        v
 BRONZE  bronze_*          exact copy, all strings, + _ingest_ts / _source_file
        v
 SILVER  silver_*          typed, standardized, de-duplicated
         rejects_*         every dropped row with a reject_reason   (bronze = silver + rejects)
        v
 GOLD    gold_dim_customer, gold_dim_loan, gold_fact_payments (window functions),
         gold_portfolio_risk_monthly  (charge-off & 30+ DPD rates by vintage x grade)
        v
 QUALITY dq_results        not-null / unique / accepted values / range / referential integrity; gate fails the job
```

## Quick start (laptop, no Databricks needed)

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt                         # needs Java 17+ installed
python -m pytest -q                                     # 9 tests
python scripts/run_local.py                             # full pipeline, prints tie-outs and risk results
```

Then follow `docs/STEP_BY_STEP.md` to run it on Databricks Free Edition.

## Results on the default synthetic dataset (seed 42)

* Raw rows: 20,200 customers, 30,300 loans, 777,494 payments (with injected duplicates, orphan keys and bad formats)
* Silver tie-out balances exactly for all three tables (bronze = silver + rejects)
* Charge-off rate rises with grade: A 0.3%, B 1.6%, C 5.4%, D 9.8%, E 15.9%, F 20.4%, G 24.0%
